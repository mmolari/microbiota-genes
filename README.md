# microbiota-genes

## Running the pipeline

The pipeline can be run using snakemake (tested on version 9.20.0)

```bash
snakemake -c1 --use-conda all
```

## Dataset

The dataset used in this project is from the paper "A comprehensive and high-quality collection of Escherichia coli genomes and their genes" by Horesh et al. (2021) https://doi.org/10.1099/mgen.0.000499.
